# Decentralized Specialized Theatrical Set Design Protection

A blockchain-based system for protecting and managing intellectual property rights of theatrical set designs through registration, verification, licensing, and attribution tracking.

## Overview

This project implements a decentralized platform for theatrical set designers to register, protect, and manage their creative works. The system ensures proper documentation, verification, licensing, and attribution through four primary contract components:

1. **Design Registration**: Records details and documentation of original stage designs
2. **Production Verification**: Documents usage in specific theatrical productions
3. **Licensing Management**: Facilitates permissions for reproduction or adaptation
4. **Attribution Tracking**: Monitors proper credit for set designers across productions

## Core Components

### Design Registration Contract
- Records comprehensive details of original set designs
- Stores visual documentation, technical specifications, and construction notes
- Timestamps creation date to establish precedence
- Generates unique digital identifiers for each registered design

### Production Verification Contract
- Documents implementation of designs in specific theatrical productions
- Links designs to venues, production companies, and performance dates
- Verifies authorized use of registered designs
- Maintains historical record of design implementations

### Licensing Contract
- Manages permissions for reproduction or adaptation of designs
- Facilitates various licensing models (one-time, limited run, regional rights)
- Automates royalty calculations and distributions
- Tracks modifications and derivative works

### Attribution Tracking Contract
- Monitors proper credit for designers across productions
- Verifies compliance with attribution requirements
- Provides verification tools for playbills, programs, and promotional materials
- Maintains reputation metrics for production companies regarding proper attribution
